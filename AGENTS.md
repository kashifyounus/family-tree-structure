# Agent instructions (family-tree-structure)

## Gap implementation

1. Start from [`docs/GAPS.md`](./docs/GAPS.md) and open GitHub issues with title prefix `[GAP]`.
2. Priority order: `[GAP][P0]` → `[GAP][P1]` → `[GAP][P2]`.
3. One pull request per issue unless the issue explicitly allows pairing.
4. Preserve Kuriosity Family Tree design tokens and Gluestack patterns in `family-tree-app/`.
5. Put cross-cutting genealogy rules/layout in `shared/`.
6. Do not expand scope into cloud sync unless the issue asks for it.
